# SUNOPlaylist

Make a web app wherein it will accept links of songs from the SUNO website and then play those music one by one. Design the site so that I can add, delete, re-arrange songs and also include play, next and randomize buttons. Also enable drag and drop capabilities to add songs. Also inlude ability to add songs with a link input box. Add the capability to save and load playlist into a local drive. Also display the song titles in the playlist itself.
